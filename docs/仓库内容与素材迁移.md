模型目录中的 args.yaml、source_path 和历史采集时间可能保留 Mac 路径，用于来源追溯，不用于后续训练命令。选择本机 dataset.yaml、PT 与新输出目录。旧 MP4 来源路径不代表视频已随 Git 上传。

新增素材保持视频来源和分组，确认记录与模型版本配套保存。原始确认 JSON 不改写，旧模型不覆盖。当前实验模型未通过精度与队友独立验收，Windows 实机验收待执行。
