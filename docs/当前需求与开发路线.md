# 当前需求与开发路线

> **平台约定（2026-09-29）：今后直接在 Windows 11 x64 + RTX 5070 上开发、测试、训练和打包，不再依赖 Mac。旧 Mac/MPS 结果仅是历史实验记录。**

## 需求优先级

用户后续要求优先于原始参考文档：场景为 Steam PUBG；允许图片、录像导入、保存、标注和训练；区分自身、队友、对手及 unknown，仅给确认的对手画框。实时屏幕帧只留内存；不读游戏内存、不注入、不修改游戏、不模拟操作、不规避反作弊。

最终交付 Windows 中文安装软件，内置经过验收的模型，支持 GUI 导入新素材、标注/批量确认、训练、导出和模型切换。当前 Python 原型、实验 ONNX 和安装脚本不等于最终产品。

## 当前基线

0.2.1 源码；52 张用户确认素材；29 自身/21 对手/6 队友，38 训练/14 验证。第 3 轮实验 ONNX 在置信度 0.5 与匹配 IoU 0.5 下对手命中 0/8；队友没有独立验证。保留这些结果供 Windows 后续比较，不改写历史成绩。

## 执行顺序

1. Windows 安装本机环境，实测 CUDA 训练和 DirectML 推理；记录版本与结果。复现检测、身份、缩放/后处理漏检及录像定位问题。
2. 主要采集 Windows 本机高质量原始录像，保留 HUD 与原始分辨率；平台素材补充多样场景。保留无框原图，框/身份另存标签，避免训练图混入预览框。
3. 开发自动选样、去重、轨迹关键帧传播、异常优先复核、批量批准/撤销。已有确认标签直接复用，新增或传播标签经用户批准后才正式训练；切镜、遮挡和关联歧义要重新确认。
4. 评估分层的人物检测、镜头自身判断、对应队标/昵称关联与跟踪规则，不用服装颜色或固定位置判断身份。只在证据明确时判断阵营。
5. 新版本训练与独立完整录像验证，分别统计对手召回、误框自身/队友、unknown、框范围、身份切换与残留；按整段录像隔离数据。量化精度/FPS/延迟验收标准尚待实际约定。
6. Windows RTX 5070、不同 DPI/显示器、覆盖层、F8、速度与稳定性验收后，完成安装程序及图形化训练组件，验证干净系统上的完整流程。

每阶段更新根目录 AGENTS、平台指南和验证记录。后续无需将素材带回 Mac，也不依赖 Mac 的虚拟环境、MPS、路径或构建流程。
