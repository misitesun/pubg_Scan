# 用户确认第3轮身份实验模型（含队友）

> **平台约定（2026-09-29）：今后直接在 Windows 11 x64 + RTX 5070 上开发、测试、训练和打包，不再依赖 Mac。旧 Mac/MPS 结果仅是历史实验记录。**

best.onnx用于人物视觉实验室0.2.1加载推理，best.pt用于后续在Windows继续训练。此目录是第3轮新模型，旧第2轮模型保留。

52张全部由用户确认的画面：29个自身、21个对手、6个队友；10张无人物样本，1个明确死亡的人物已排除。38张训练、14张验证，按整段录像分组，无同一录像跨训练/验证分割。新增14张队友录像全部进入训练，原第123集14张验证画面及其标签保持一致。本次MPS训练100轮，输入960，学习率0.001。

实际应用ONNX，置信度0.5、匹配IoU0.5：验证画面的8个对手命中0个，对手候选0个，其中0个与已标注自身重叠。上一轮同组对手命中0/8。独立第120集确认帧中的1个对手命中0个，该帧未参与训练。命中率依据人物框与身份同时正确计算，并非完整游戏准确率。

ONNX实际加载、真实录像推理线程运行及停止清理已通过；5张画面PT/ONNX的类别、数量、置信度抽查一致。这5张含训练画面，仅用于验证导出一致性，不作为独立识别精度验证。

本轮已有6个队友训练实例，但它们全部来自同一段录像，验证集没有队友，队友识别与排除效果尚未独立验收。软件仍是局部队标模板实验，完整队伍名单、昵称自动识别与人物关联尚未实现验收。训练增加队友类别，并不代表已学会队标判断规则。

按上述固定阈值检查，8个对手均漏检，本轮未改善该项检验；当前精度不适合可靠实时画框。这是小样本实验模型；需补充不同录像中的远景、遮挡、多穿搭及队友样本并经用户确认，再用未参与训练的整段录像检查误框、漏检和身份切换。Windows11+RTX5070安装包尚未构建和实机验收。

Windows继续训练：复制完整“PUBG用户确认训练集-52张”目录，选择其dataset.yaml与本目录best.pt。软件推理：选择本目录best.onnx，先导入录像测试。args.yaml是Mac实际训练参数记录，跨电脑使用dataset.yaml，不直接复用其中的绝对路径。
