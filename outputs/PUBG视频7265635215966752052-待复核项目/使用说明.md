# PUBG 视频人物标注项目

> **平台约定（2026-09-29）：今后直接在 Windows 11 x64 + RTX 5070 上开发、测试、训练和打包，不再依赖 Mac。旧 Mac/MPS 结果仅是历史实验记录。**

来源：https://www.douyin.com/video/7265635215966752052

该视频通过已登录浏览器当前播放的视频元素保存，未读取或导出账号密码、Cookie，也没有使用第三方解析站。本次已验证该具体视频能够获取，不代表其他抖音视频或直播均支持。

`samples/` 保存每约 3 秒抽取的一张原分辨率图片；`project.json` 是可直接在人物视觉实验室中打开的项目；`source.json` 记录原始视频属性、抽样位置和预标注统计。

人物框由通用 YOLO11n 基线模型以 0.20 置信度生成，仅作为待复核草稿。所有图片的 `reviewed` 均为 false。没有预测框不表示画面没有人物，特别需要检查远景、蹲姿、趴姿、遮挡和运动模糊。

在软件「素材与标注」页面选择「新建 / 打开项目」，打开本目录。逐张核对、补画所有可见游戏人物的框，删除错误框后保存。人物统一为 person，不区分敌我或衣服。没有人物的图片必须人工确认后才能作为负样本。字幕覆盖、地图图标和游戏 UI 都不应被标为人物。

同一录像的所有抽帧属于同一个素材组。不能随机将相邻画面拆进训练集与验证集；本项目单独导出训练集会要求补充另一个独立素材组。建议另外提供不同对局、不同地图的视频，作为独立验证素材。

当前仅完成视频获取、抽帧和预标注，没有用本视频微调模型，也没有产生本视频训练的 best.onnx。完成标注并准备独立验证素材后再训练。

素材使用应符合来源授权；扫码登录本身不等于取得作者的训练素材使用许可。
