# 基线模型使用说明

> **平台约定（2026-09-29）：今后直接在 Windows 11 x64 + RTX 5070 上开发、测试、训练和打包，不再依赖 Mac。旧 Mac/MPS 结果仅是历史实验记录。**

配套文件：YOLO11n-person-baseline.onnx。它由 Ultralytics 官方 yolo11n.pt 导出，属于 COCO 预训练通用目标检测模型，不是使用这批图片微调得到的 PUBG 模型。

在人物视觉实验室的「画框验证」页面选择该 ONNX，人物类别编号为 0。默认录像回放模式；屏幕测试逻辑仍独立保留，没有自动开启。

本次只检查静态角色图。低背景复杂度下的检测结果不能用于宣称游戏实际精度；模型也可能把人体 UI 图标判成人物。应使用独立游戏录像验证误检、漏检、坐标位置与远景效果。

权重来源：https://github.com/ultralytics/assets/releases/download/v8.3.0/yolo11n.pt

模型说明：https://docs.ultralytics.com/models/yolo11/

本地导出：FP32、RGB NCHW、640×640、batch=1、nms=False。输出 [1,84,8400]。本工具只保留人物类别 0。

官方模型使用 AGPL-3.0 / Enterprise 授权方式；此处保留来源与授权信息，不改变原模型授权。
