# 静态人物素材项目

> **平台约定（2026-09-29）：今后直接在 Windows 11 x64 + RTX 5070 上开发、测试、训练和打包，不再依赖 Mac。旧 Mac/MPS 结果仅是历史实验记录。**

包含 11 张原始角色 PNG、14 个初始人物框，统一类别 person。原文件未修改，透明通道完整保留。

在人物视觉实验室中点击「新建 / 打开项目」，选择本目录，可以逐张查看人物框。所有框均为初始草稿，未标记为人工确认。请核对身体边界、裁切人物和持有武器，点击「保存人物标注」后才能导出到训练数据集。

3 张 T_ 开头的轮廓/UI 图片暂不作为真实角色训练正样本。四人合照保留 4 个框，不拆成 4 个独立来源；两张黑上衣、白长裤角色图片保持同一个素材组。

这批图片适合起步和外形参考，不是完整的 PUBG 训练集。角色穿搭不同仍应统一标注 person，不按衣服分类。现有素材主要是透明背景、站立近景；需要实际录像补足蹲姿、趴姿、远景、遮挡、光照和地图背景。

透明通道可供后续训练时做前景/背景处理，但轮廓、肢体与穿搭特征仍由模型共同学习，不能保证模型自动完全忽略衣服。不要仅用纯色背景版本训练，也不要把同一人物的增强版本分别放入训练集和验证集。

当前没有用这 11 张图训练并交付所谓精准人物模型。公开预训练模型基线检查与最终微调、游戏回放验收是不同证据层级。
