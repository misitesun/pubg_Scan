# PUBG 身份样本最终复核

> **平台约定（2026-09-29）：今后直接在 Windows 11 x64 + RTX 5070 上开发、测试、训练和打包，不再依赖 Mac。旧 Mac/MPS 结果仅是历史实验记录。**

双击「开始复核.html」。默认38张全部待确认，未把你的确认自动代填。

1. 查看原图、人物框、时间戳和判断依据。可切换「仅对手画框」。总览目录和标注图目录方便直接看图片。
2. 修改每个人物的身份。点击「这张正确」才能确认；漏框或范围不对时选「需修正」，写出人物编号与问题。
3. 导出「PUBG-我的身份确认结果.json」并保留；可交回继续处理，也可在0.2工具打开「PUBG身份素材-第121至123集」项目，点击「导入复核页确认结果」。
4. GUI默认「仅导出用户确认」，待确认和需修正样本不进入正式训练。框范围如有改动需在工具中改框，旧复核页不能覆盖新框。

本包来自重阳第121、122、123集，约14分52秒录像的298张候选中筛选38张：23个自身、11个对手、7个不确定人物，6张无人物场景。角色是助手结合画面及上下文的建议，需由你最终核对。未提供真实队友样本，本包不证明队友排除已通过。

首轮四类身份模型只使用这些未确认建议做实验；独立第123集14张验证中，对手召回率0，不能用于可靠实时画框。确认标签后仍需补充队标、远景、遮挡和不同穿搭样本，再训练并使用整段独立录像验收。先前你确认的第120集样本未加入本轮训练。
